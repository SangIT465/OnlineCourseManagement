# Phần lưu trữ

`legacy-razor/` giữ nguyên các Razor Pages, tài nguyên tĩnh và hướng dẫn cũ để đối chiếu hoặc phục hồi sau khi tách FE/BE. Các file này không thuộc solution backend và không được Vite sử dụng.

`local-build/` chỉ chứa đầu ra build cũ trên máy (bin/obj, được Git bỏ qua). Thư mục này không phải thành phần đang chạy.

Mã nguồn đang sử dụng nằm tại `frontend/` và `backend/`. Hãy theo hướng dẫn README ở thư mục gốc thay cho hướng dẫn trong archive.
